# TASTY CROUSTY Business School — site web parodique

Site vitrine responsive en français avec :
- Bachelor Tasty Crousty et PGE Master Poulet (onglets interactifs)
- 8 spécialisations : Labubu, Growth Hacking de la Sauce, Option 67, Battle d'Auras Scooba, etc.
- Section pédagogique, débouchés fictifs, recrutement, FAQ
- Formulaire d'admission fonctionnel côté navigateur, avec sélection synchronisée et réponse humoristique
- Zéro dépendance, aucun backend, aucune donnée envoyée

## Ouvrir le site
Double-cliquer sur `index.html` : fonctionne directement, même hors ligne.

## Publier sur GitHub Pages
1. Créer un dépôt GitHub public.
2. Envoyer `index.html` à la racine du dépôt.
3. Aller dans Settings > Pages > Build and deployment > Deploy from a branch, choisir `main` et `/ (root)`.
4. Le site sera visible à l'URL Pages du dépôt.

## À savoir
Site humoristique/parodique, aucun diplôme reconnu ni inscription réelle. Le formulaire **ne transmet aucune information** et ne les conserve pas. Pour recevoir de véritables candidatures, il faudrait un backend, une politique de confidentialité et un traitement conforme au RGPD.
